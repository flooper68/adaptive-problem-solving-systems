# Framework adaptation

Review a proposed compiled-knowledge draft and decide whether it becomes canonical APS knowledge.

1. Confirm the linked evidence, problem, strategy, and intended later behavior.
2. Compare the draft with current `framework/` pages and prior decisions. State the strongest case against the proposal and any plausible smaller alternative.
3. Check that source claims, interpretation, uncertainty, and authorized decisions remain distinguishable.
4. Decide approve, revise, defer, or reject. Silence and exploratory language are not approval.
5. On approval, write only the reviewed scope to the canonical wiki paths, session-bound; update the changelog and every affected live reference.
6. Run verification and record the decision, evidence, changed paths, validation, and next trigger in the task and working-session record.

Repository backup convergence follows accepted writes asynchronously. A backup commit is never adaptation authority.
