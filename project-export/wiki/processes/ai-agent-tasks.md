# AI-agent tasks

Use this process when an AI agent executes a Chaos House task for APS Framework Operations.

1. Start the task-bound session and follow the pinned process delivered with it.
2. Orient from the task, problem, canonical framework pages, relevant records, and prior sessions. Keep scope bounded to the task.
3. Post concise progress and preserve decisions, validation, and blockers in the task/session history.
4. Draft any normative framework change for review; do not write it into canonical `framework/` pages before the required maintainer approval.
5. After approval, apply session-bound canonical actions, verify the written state, update the task and affected problem/current-state views, and provide the structured completion result expected by the runner.

Agents never use the R54 backup repository as a worktree and never treat backup push success as task completion. If owner-only actions are required, the task must be routed to an owner session or split before execution.
