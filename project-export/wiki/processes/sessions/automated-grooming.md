# Automated grooming

Prepare grooming dispositions autonomously, have an independent reviewer check them, and require per-item maintainer approval before mutation.

1. Declare the exact records, tasks, problems, readings, and session lessons in scope.
2. Draft one evidence-bounded disposition and exact canonical mutation per item; do not apply it.
3. Have an independent reviewer check faithfulness, duplication, strategy fit, propagation, and whether every keep/deferral has a trigger.
4. Present each proposal with rationale, strongest alternative, reviewer findings, and resulting mutation.
5. Apply only individually approved mutations through session-bound Chaos House actions. Unapproved items remain unchanged.
6. Verify the resulting inbox, task/problem state, selected next work, and affected current-state views; retain the complete working-session record.

No Git staging or push is part of grooming. R54 backup converges from accepted Chaos House state asynchronously.
