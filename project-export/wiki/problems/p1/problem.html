# The APS MVP is unfinished and has not run its complete loop

Parent: the APS Framework Operations System (root problem).

The APS framework has more concepts and surfaces than one working loop needs,
and the loop has never run end to end: until 2026-08-21 no real need had gone
through grooming, a change, verification, and an approved adaptation that a
later run actually used, and teach-back and adversarial review have never run
at all. Until the loop has run, we do not know which parts of the framework
are necessary, and the maintainer cannot explain and run the process unaided
(answer on 2026-08-21: "no").

What "solved" looks like, how we measure movement, and how we approach it are
stated in this problem's verification and strategy pages; the latest meaning
of the readings is in its current state.
